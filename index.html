En attente
Dans Excel, prépare 5 colonnes dans cet ordre : Date · Catégorie · Poste · Montant · Commentaire (facultatif). Sélectionne les lignes (sans les titres), copie-les, puis colle-les ici.
Exemple : 05/11/2026 · Dépenses variables · Transport · 2500 · Yango. Catégories : Revenu, Dépenses fixes, Dépenses variables, Epargne. Les postes inconnus sont créés ; les lignes déjà présentes sont ignorées.
